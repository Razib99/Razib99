Computer Science and Engineering graduate from North South University. I specialize in low-level systems programming, scalable data architecture, and wireless cybersecurity. 

### 🔧 Technical Arsenal
* **Core Languages**: Python, C, C++, Rust, Java, Dart, Bash
* **Data & Machine Learning**: PyTorch, PostgreSQL, Data Pipelines, Anomaly Detection
* **Infrastructure & Tools**: Linux, Docker, QEMU, Wireshark, Firebase, Flutter

### 🚀 Selected Engineering Projects
* **[BitDrop](https://github.com/Razib99/BitDrop)**: Audiophile cloud streaming engine built in Rust featuring 64-bit float DSP and bit-perfect DAC output.
* **[Medical CV Segmentation](https://github.com/Razib99/medical-cv-segmentation-pipeline)**: End-to-end PyTorch pipeline for precise brain tumor MRI segmentation using U-Net and SegFormer.
* **[xv6 Kernel Enhancements](https://github.com/Razib99/xv6-kernel-enhancements)**: Modified MIT's xv6 RISC-V kernel to include a priority-based CPU scheduler and custom system calls.
* **[Specter CSI](https://github.com/Razib99/Specter_CSI_Project)**: Wi-Fi Channel State Information (CSI) extraction for device-free spatial presence detection.

### 🔬 Active Research
* **Formal Verification**: Exploring rigorous mathematical methods for proving the correctness of critical systems.
* **eBPF (Extended Berkeley Packet Filter)**: Investigating kernel-level programmability for advanced network observability and security tracing.
